Cómo se cuentan

  • Solo las materias nuevas aprobadas del trayecto elegido suman 3 créditos electivos cada una.
  • Regular, cursando, promoción, libre o abandono no suman créditos hasta la aprobación.
  • Las materias compartidas con Sistemas no se duplican ni se vuelven a contar como electivas.
  • Las materias nuevas no cambian el total de 36 materias obligatorias de Ingeniería.

La asignación de 3 créditos es el criterio configurado para este seguimiento. El reconocimiento académico se confirma en la Facultad.
